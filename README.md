Inspired by the movie _Tron: Legacy_, we built real life Tron identity discs! The microprocessor is the Adafruit Feather M0, and the LEDs used are from Adafruit as well. We then combined that with a 4000 mA battery and a button to finish off the electronics. Then Luke designed and printed the disc shell!
