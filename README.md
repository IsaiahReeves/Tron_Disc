Inspired by the movie _Tron: Legacy_, we built real life Tron identity discs! The microprocessor is the Adafruit Feather M0, and the LEDs used are a WS2812B LED strip. We then combined that with a 4000 mA battery and a TTP223B touch sensor to trigger the outer ring. Then Luke designed and printed the disc shell!
